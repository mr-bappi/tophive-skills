01 / INSTALLATION

For coding agents.

Use the open Skills CLI to install from the public GitHub repository into supported coding agents.

TERMINAL
MAC / LINUX / WINDOWS
npx skills add mr-bappi/tophive-skills -g

NOTE / 01

mr-bappi is the current GitHub repository owner—not an account or machine requirement. Global installation makes this skill available across local projects. Your CLI may prompt you to select a supported agent.

03 / USE THE SKILL

Ask for the right output.

Web & UI Design distinguishes landing-page design, operational dashboard UI, and visual review. Start with a concrete task and real product sources.

EXAMPLE / DESIGN REQUESTEDIT BEFORE USING
Use Web & UI Design to propose three original creative directions for an AnyLicense standalone SaaS landing page. Verify actual product capabilities. Do not create a Gutenberg product description.

A product URL provides context. It is not permission to modify production files or deploy anything.

04 / TRUST & ACCESS

Instructions, not access.

Skills provide guidance and reference files. Installing one does not grant access to your Mac, private code, browser sessions, production systems, tokens, hosting, or payment details.

SKILLS PROVIDEWorkflow instructions

Readable rules, examples and links that guide the agent's work.

SKILLS DO NOT GRANTSystem permissions

Tools, credentials and production access need separate authorization.

Source of truth

Real product documentation and the target repository’s AGENTS.md override generic design examples. Conceptual screenshots are not operational proof.

05 / SOURCE & PUBLISHING

Open. Readable. Inspectable.

Published TOPHIVE Skills source is available on GitHub. Future skills should be reviewed, evidence-backed and scoped to a clear purpose. No automatic user-submitted publishing workflow is available yet.
