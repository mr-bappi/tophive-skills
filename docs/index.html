01 / INSTALL

One command.

The open Skills CLI installs from a public GitHub repository into supported coding agents. This is distinct from ChatGPT cloud Skills upload. CLI documentation ↗

npx skills add mr-bappi/tophive-skills -g

Global installation makes the skill available across local projects. Your CLI may prompt you to select the target coding agent.

02 / CHATGPT

Upload the portable skill.

For eligible ChatGPT accounts, use the Skills upload flow and select the packaged ZIP. This does not automatically sync the local GitHub skill with ChatGPT.

Download the portable Skill ZIP ↗

03 / USAGE

Give it a real design task.

The skill routes landing-page design, information-dense dashboard UI and visual review separately. A product URL is information—not permission to modify the website.

Use Web & UI Design to propose three original creative directions for an AnyLicense standalone SaaS landing page. Verify actual product capabilities. Do not create a Gutenberg product description.
04 / TRUST

Know the boundaries.

Skills contain instructions and references. Installing one does not grant access to local files, browser sessions, private code, production systems, tokens, hosting or payment details. Always review SKILL.md and any source before use.

Source of truth

Real product documentation and the target repository's AGENTS.md override a generic design example. Never substitute conceptual screenshots for operational proof.

05 / CONTRIBUTE

Open and inspectable.

All currently published TOPHIVE Skills content is available in the GitHub repository ↗. Future skills should be evidence-backed, scoped to one purpose, and reviewed before release. No automatic user-submitted publishing workflow is available yet.
