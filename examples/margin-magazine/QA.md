# MARGIN — actual QA report

Date: 25 October 2026 (Asia/Dhaka).

## Design approach

Selected visual system: independent print-journal / art-literature hybrid. Warm paper (#f3f0e8), deep ink (#222321), rust-red (#b4452e), editorial serif display, utilitarian sans labels, asymmetrical story-grid, original local SVG illustrations. Chose a typography-led treatment over a generic SaaS template.

Full automated WCAG/axe audit was **NOT TESTED**.

## Limitations

- **NOT TESTED:** Safari, Firefox, live HTTP deployment, external hosting, real screen readers, and network/lighthouse performance.
- **Demo only:** No backend/CMS, author portal, submission inbox, paid membership, actual newsletter delivery, or persistent data.
- **Fictional editorial content:** Contributors, articles, publication issue and editorial claims are invented for this design exercise and labeled accordingly. No testimonials, audience statistics or success metrics were created.
- **Offline design:** CSS uses platform fonts only; type metrics may vary by operating system. All supplied illustrations are local original SVG assets.
- **Without JavaScript:** The mobile menu still shows its navigation links; article dialogs and filters require JavaScript (article links fall back to the issue index).

## Reproduce test

Install Python `playwright` package, ensure Chromium is installed, then run `python tests/qa.py` in the project folder. This harness inlines the page to avoid administrator restrictions on local URLs. The browser screenshots in the working session are separate from the lightweight source ZIP.
