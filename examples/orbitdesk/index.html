Testing & limitationsBrowser checks, source provenance and prototype boundaries+

The original source was tested as a standalone fictional prototype. Its QA report records six responsive viewport checks, real UI interactions and an additional 320px overflow check. The original session tested rendered source using Playwright; this site's embedded preview is also checked separately.

Assistive technology
Screen reader and full WCAG audit not tested

No backend, accounts, saved data, external integrations, email collection or real customers. All example tasks are illustrative and reset when reloading. Safari and real-device testing were not part of the source QA.

Product boundary: Illustrative product and sample tasks only. No user accounts, persistent task storage, workspace API, or third-party integrations.

Evaluation distinction: OrbitDesk is a working manual trial guided by source instructions. The original QA report explicitly notes that the 15-file v1.3 candidate was not verified as the active shared installation at the time. This example is not proof of automatically invoked Skill v1.3.0 and does not count toward the official 24-run benchmark.
