PURPOSE

Design the right artifact.

AI agents can confuse tasks when they see a product URL. Web & UI Design routes by the user's requested output. A new landing page stays a website design task—not a Gutenberg product description or a Rank Math settings package.

What it doesn't do

Installing this skill does not give an agent access to your Mac, applications, production systems or private repositories. Those require their own permissions and tools.

THREE WORKFLOWS

One skill. Focused jobs.

Website design

Ground the product brief in verified facts, develop art directions, shape a buyer-driven page, and build a responsive standalone prototype when requested.

Product UI

Review actual dashboards and workflows, preserving navigation, tables, forms, control density and meaningful states before styling. Never convert an operational UI into a marketing landing page.

Visual review

Critique screenshots and actual renders, prioritize specific improvements, and report what was genuinely tested.

INSPECT THE SOURCE

Seven readable files.

The portable package includes one skill entry, three task-specific references (including dashboard rules), display metadata and two branded icon assets. No large gallery dump.
